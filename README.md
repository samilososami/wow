### ✦ Características

*   **Comunicación en Tiempo Real**: Sistema de chat fluido con soporte para múltiples conversaciones simultáneas.
*   **Gestión de Perfiles**: Personalización de avatares, estados y biografía de usuario.
*   **Integración Multimedia**: Almacenamiento y gestión de imágenes para perfiles y estados mediante Cloudinary.
*   **Sistema de Cuentas**: Registro seguro y autenticación de usuarios.
*   **Interfaz Legacy**: Diseño fiel al estilo de mensajería de principios de los 2000 con componentes web modernos.

### ✦ Requisitos

*   Python 3.8+
*   Cuenta de Cloudinary (para la gestión de medios).

### ✦ Instalación

1.  Clone el repositorio:
    ```bash
    git clone https://github.com/samilososami/wowmessenger.git
    cd wowmessenger
    ```
2.  Instale las dependencias:
    ```bash
    pip install -r requirements.txt
    ```
3.  Configure las variables de entorno necesarias para la base de datos y Cloudinary.
4.  Inicie el servidor:
    ```bash
    python server.py
    ```
